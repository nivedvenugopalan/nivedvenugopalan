# About Me

Hi, I'm Nived, a Mechanical Engineering student at IIT Gandhinagar from India with a strong interest in Physics, Mathematics, Computer Science, and Robotics. I enjoy exploring challenging problems in mathematics, physics, and software development.

I've been programming for over six years, a journey that began while living in Qatar. Since then, I've worked on a variety of projects ranging from data analysis tools to automation, electronics, and full-stack applications. I particularly enjoy building projects that combine programming with real-world engineering applications.

### Current Interests

* Mechanical Engineering and Robotics
* Physics and Mathematics
* Data analysis and visualization
* C++ and Python development
* Electronics and embedded systems
* Teaching and explaining technical concepts

### Beyond Academics

When I'm not studying or coding, you'll usually find me playing football, experimenting with electronics, creating physics problems, exploring new technologies, or gaming with friends.
